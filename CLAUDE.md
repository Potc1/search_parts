## Описание проекта

**LLM_for_zap** – это система подбора запасных частей для тракторной и сельскохозяйственной техники с использованием больших языковых моделей (LLM) и семантического поиска. Пользователь вводит запрос (например, артикул детали или название модели трактора), система проверяет релевантность запроса, при необходимости ищет информацию в векторном хранилище Qdrant и формирует структурированный ответ эксперта.

## Архитектура

- **Frontend (Streamlit)** – `app.py` – отвечает за UI, аутентификацию и передачу запросов в LLM‑логика.
- **Backend (FastAPI)** – `server/main.py` – предоставляет эндпоинты `/register` и `/login` и хранит данные пользователей в SQLite‑БД (`users.db`).
- **LLM‑логика** – `llm/chats.py` (оригинал) и `llm/chats_new.py` (рефакторинг) – управляет проверкой запроса, поиском в Qdrant и построением экспертного промпта.
- **Векторное хранилище** – Qdrant (`http://localhost:6333`) + модели Sentence‑Transformers (`ai-forever/ru-en-RoSBERTa`).
- **Модели** – Ollama (локальная) и совместимый OpenAI‑endpoint (`http://localhost:11434/v1`).

```
User -> Streamlit UI -> PrepareAnswer (чаты) ->
   ├─ Censor (mini‑модель) → проверка безопасности
   ├─ Поиск в индексе (name / article)
   ├─ Парсер группы запчастей
   ├─ RAG (QueryFinder) → контекст из Qdrant
   └─ Большая модель (big) → окончательный ответ
```

## Установка и запуск

1. **Установить зависимости**
   ```bash
   pip install -r requirements.txt
   ```
2. **Запустить Qdrant** (можно через Docker)
   ```bash
   docker run -p 6333:6333 qdrant/qdrant
   ```
3. **Запустить Ollama‑сервер** и нужную модель (например, `gemma4`) – см. документацию Ollama.
4. **Запустить бек‑энд**
   ```bash
   uvicorn server.main:app --reload
   ```
5. **Запустить фронт‑энд**
   ```bash
   streamlit run app.py
   ```

## Как добавить новые группы запчастей

- Добавьте JSON‑файл с описанием групп в папку `groups/` (пример `GROUPS_MTZ82.json`).
- Обновите словарь `part_model_names` в `llm/chats_new.py`, указав путь к новому файлу.
- Перезапустите приложение.
